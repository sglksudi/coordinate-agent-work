# 按需模板

使用项目已有记录。模板不是额外文书任务，短工作可简化。

## 任务卡

```text
任务ID / 修订 / 负责人 / 状态：
任务类型 / 目标模型与档位 / 实际配置 / 工具确认或未知：
用户可见结果：
必要上下文与引用：
授权依据 / 允许对象 / 禁止项：
前置结果 / 未知项：
完成条件 / 独立验证范围：
交付位置 / 接收者 / 下一动作：
```

## 交付通知

```text
任务ID/修订；结论；报告路径与必要版本；未验项；
停止写入或保活实例身份；下一责任。
```

## 安全交接

```text
目标与当前任务：
最新授权及禁止项（准确来源）：
已完成证据与冻结版本：
关键发现、失败方法和决策原因：
未解决问题及恢复条件：
在途命令/服务身份与写入归属：
上下文采样及继续/压缩/交接依据：
下一责任与具体动作：
```

旧方先保存并结束相关写入；新方只读核对材料和现场。确认接手和唯一责任后执行。不要把聊天idle等同于全机没有后台服务。

## 用户操作卡

```text
卡点与影响：
已完成的独立工作：
为何需要本人操作：
具体一步与成功表现：
恢复后谁继续什么：
```

## 观察是否改善

在已有记录中记录用户催单、同义授权重复、未变化重测、用户提醒换会话以及交付接手情况。接手时间仅使用实际时间戳；缺数据写未知。阶段通知说明用户当前能用什么，不用报告数量作进度。
